# Changelog

## [1.0.0] - 2026-11-28
### Added
- Template based on Unity's Universal 2D 7.0.0 (Unity 6000.6), without the Welcome tutorial.
- Flow, Type Reference, VContainer, UniTask, R3, ObservableCollections, NuGetForUnity, Newtonsoft.Json, Alchemy and LitMotion.
- NuGet libraries shipped in `Assets/Packages` so a new project compiles on first open.
- Newtonsoft converters for R3 reactive properties and ObservableCollections.
